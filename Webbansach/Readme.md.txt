 📚 Website bán sách (StoreSach)

 🚀 Giới thiệu
Website bán sách với các chức năng:
- Đăng nhập / đăng ký
- Xem sản phẩm
- Giỏ hàng
- Đặt hàng
- Quản lý admin

 🛠 Công nghệ sử dụng
- ASP.NET / C#
- SQL Server
- Bootstrap

 ⚙️ Hướng dẫn cài đặt

 1. Clone project
git clone https://github.com/GiaVy12/Web-ban-sach.git

 2. Import database
- Mở SQL Server
- Tạo database: StoreSach
- Chạy file: database/StoreSach.sql

 3. Cấu hình kết nối
- Mở Web.config
- Sửa connection string theo máy bạn

 4. Chạy project
- Mở bằng Visual Studio
- Nhấn Run
